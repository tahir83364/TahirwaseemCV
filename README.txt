TAHIR WASEEM — RESPONSIVE PERSONAL PORTFOLIO

Included files:
- index.html — responsive website for mobile phones, tablets and desktop.
- profile.jpg — your profile photo.

Responsive features:
- Mobile navigation menu
- Responsive layouts and typography
- Touch-friendly buttons
- Flexible cards and skill sections
- Image sizing for smaller screens
- Reduced-motion accessibility support

Preview:
Extract the ZIP and open index.html in a browser. Keep profile.jpg in the same folder.

Publish:
Upload both index.html and profile.jpg to the root of a GitHub repository. Enable GitHub Pages from Settings → Pages → Deploy from a branch → main / root.
